# 小王的技术站

欢迎来到我的技术站，这里记录 Android 驱动开发、BSP 移植、问题调试的知识库。

---

## 📂 驱动文档

按 **模块 → 厂商 → 芯片型号** 组织，涵盖：

- 🖥️ LCD / 显示驱动
- 🔋 Charger / 充电管理
- 📷 Camera / 摄像头
- 👆 TP / 触摸屏
- 📡 Sensor / 传感器
- 🛰️ GPS / 定位
- 🎵 Audio / 音频
- 🌡️ Thermal / 温控
- 💾 Memory / 存储
- 📶 NFC / 近场通信
- 💡 LED / 指示灯
- ⚡ GPIO / 通用输入输出
