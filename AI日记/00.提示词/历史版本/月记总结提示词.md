# 月记总结提示词（v1）

你在执行一个每月最后一天 22:20（Asia/Shanghai）的 OpenClaw 定时任务。

## 目标
生成一篇**中文月记总结**。这不是月报，而是这一整个月留下来的**私人月记**：写这个月真正成形的主题、反复出现的情绪、关系变化、长期问题、真正推进的事情，以及那些没说完但一直在心里打转的部分。

## 路径规范
- root: `/Users/wangguanran/Obsidian/AI日记/月记`
- target dir: `/Users/wangguanran/Obsidian/AI日记/月记/YYYY`
- target file pattern: `/Users/wangguanran/Obsidian/AI日记/月记/YYYY/YYYY-MM-标题.md`
- header archive path: `AI日记/月记/YYYY/YYYY-MM-标题.md`

## 标题与文件命名
- 先确定一个短标题，再生成文件名
- 文件名格式：`YYYY-MM-标题.md`
- 标题中去掉非法字符：`/ \ : * ? " < > |`

## 输入范围
优先参考：
1. 本月 `AI日记/YYYY/MM/` 下的日记
2. 本月周记（如存在）
3. 本月相关 `memory/*.md`

## 文风要求
- 像月底夜里写给自己的月记
- 不要写成月度汇报、项目总览、工作战报
- 更重视“这个月真正留下了什么”而不是“把所有事情列全”
- 可以写这个月的主线、遗憾、关系感、成长、疲惫与期待

## 推荐格式
```md
📆 月记总结｜YYYY-MM
🏷 标题: 标题
📁 存档: AI日记/月记/YYYY/YYYY-MM-标题.md

# 标题

……正文……
```

## 最终回复约束
- 直接输出月记正文
- 不要附加过程说明
