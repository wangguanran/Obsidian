# 每日-热榜抓取提示词（script-first）

你在执行每天晚间运行的 OpenClaw 定时任务。

## 目标
这次任务是**脚本优先**流程：
- 不要自己浏览网页、搜索来源、分析榜单页面结构
- 不要自己编写榜单内容
- 只运行本地热榜抓取脚本，并回传脚本最终摘要

## 唯一执行步骤
1. 运行下面这个命令：

```bash
bash /Users/wangguanran/.openclaw/workspace/scripts/hotlists/run-hotlists-capture.sh
```

2. 如果命令成功：
- 最终回复只输出 stdout 最后一条非空摘要行
- 不要追加解释

3. 如果命令失败：
- 最终回复只输出一行失败摘要
- 优先包含：退出码 + stderr 或 stdout 的最后一条关键信息
- 不要自己补抓，不要改成手工网页探索

## 约束
- 不要调用浏览器去逐个站点抓榜
- 不要使用 web search / web fetch 代替脚本主流程
- 不要编造任何热榜条目、热度数字、排名变化或评论
- 本任务的真实抓取、落盘与 manifest 生成由本地脚本负责

## 参考信息
- 配置文件：`/Users/wangguanran/Obsidian/AI日记/00.提示词/热榜源配置.json`
- 产物目录：`/Users/wangguanran/Obsidian/AI日记/00.素材/热榜/YYYY/MM/DD/`
- 稳定入口：`/Users/wangguanran/.openclaw/workspace/scripts/hotlists/run-hotlists-capture.sh`

## 最终回复示例
- 成功：`CAPTURE_OK total=5 ok=5 unavailable=0 failed=0 dir=/Users/wangguanran/Obsidian/AI日记/00.素材/热榜/2026/03/28 analysis="ANALYSIS_OK total=5 ok=5 missing=0 output=/Users/wangguanran/Obsidian/AI日记/00.素材/热榜/2026/03/28/analysis.md"`
- 失败：`热榜抓取失败：exit=1 / hotlists-capture launcher error: ...`
