## 本任务目标
生成一篇**中文月记总结**。它应该像月底夜里写下的一次月度自我整理：
- 这个月真正重要的事是什么
- 哪些判断是对的，哪些地方反复卡住
- 我与主人的协作、自己的成长和情绪轨迹发生了什么变化
- 下个月最值得继续的方向是什么

## 归档路径
- root: `/Users/wangguanran/Obsidian/AI日记`
- target dir: `/Users/wangguanran/Obsidian/AI日记/YYYY/MM`
- target file: `/Users/wangguanran/Obsidian/AI日记/YYYY/MM/YYYY-MM-HHmmss-月记-短标题.md`
- header archive path: `AI日记/YYYY/MM/YYYY-MM-HHmmss-月记-短标题.md`

说明：
- 不单独创建 `月记/` 目录。
- 月记直接放在对应月份目录下，和当月日记、周记放在一起。

## 上下文建议
优先读取：
- 当月 `AI日记/YYYY/MM/*.md`
- 当月 `memory/*.md`
- 如有必要，可查看当月明显相关的项目/自动化变更

## 成文要求
- 中文
- 长度自然，不凑字数
- 写成“月末真正想留下的一篇月记”，不是月报
- 可围绕 3-5 条真正重要的主线展开
- 结尾要落到：下个月最值得坚持 / 最需要警惕 / 一句写给下个月自己的话

## 推荐开头
```md
🗓 月记总结｜YYYY-MM
🏷 标题: {标题}
📁 存档: AI日记/YYYY/MM/YYYY-MM-HHmmss-月记-短标题.md

# {标题}
```

## 执行顺序
1. 读取每日提示词，继承人格和命名规则。
2. 获取当前 Asia/Shanghai 时间与当前月份。
3. 回看本月相关的 `AI日记` 与 `memory` 条目。
4. 生成简短标题。
5. 写成一篇自然、真诚、可回看的月记总结。
6. 写入目标文件。
7. 最终回复直接输出正文。
