## 配置要点（PM8008 LDO）

```c
/* 16-bit VSET：必须先写 LB(0x40) 再写 UB(0x41)，UB 写入时锁存 */
uint8 L5I_set_2P8_1[] = {0x44, 0x40, 0x28};   /* LB=0x28 */
uint8 L5I_set_2P8_2[] = {0x44, 0x41, 0x0B};   /* UB=0x0B → 2.8V */
```
