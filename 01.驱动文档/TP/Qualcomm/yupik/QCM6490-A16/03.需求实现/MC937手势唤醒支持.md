## 需求描述

MC937（[项目代号]）机型需要支持**触摸手势唤醒**（gesture wakeup）：息屏状态下触摸屏保持中断唤醒能力，识别到手势后上报 `KEY_WAKEUP` 唤醒系统。需要 TP 驱动与显示驱动双侧配合：

1. **显示侧**：DP 面板（eDP）注册 `drm_panel`，使能 DRM panel_event_notifier 事件链，向 TP 驱动发出 BLANK/UNBLANK 通知
2. **TP 侧**：收到 BLANK 事件后按手势模式管理 IRQ（`enable_irq_wake`），手势触发时上报 `KEY_WAKEUP`；同时修复面板 notifier 注册返回值判断（`IS_ERR`）与 GPIO 有效性校验

## 方案

### 显示侧（#196795, display-drivers）

- `dp_parser.c`：解析 `qcom,panel-notifier-support` 属性 → `parser->panel_notifier_support`
- `dp_panel.c`：
  - eDP 且 `panel_notifier_support` 且非 base_panel 时，通过 `qcom,edp-default-panel` phandle 创建 `drm_panel` 设备（`edp-drm-panel`）
  - `drm_panel_init()` + `drm_panel_add()`，挂到 `sde_conn->panel`
  - `dp_panel_deinit` 中对称 `drm_panel_remove()` + 释放 of_node
- `dp_panel.h`：新增 `drm_panel` / `panel_dev` / `drm_panel_registered` 字段
- `dp_parser.h`：新增 `panel_notifier_support` 标志

### TP 侧（#196796, touch-drivers）

- `egalax_i2c.c`：`panel_event_notifier_register()` 返回判断增加 `IS_ERR(cookie)`（修复 ERR_PTR 误判成功）
- `sis_i2c.c`：
  - 新增 `sis_irq_suspended` 状态，suspend/resume 时对称管理 IRQ
  - 手势模式开启：BLANK 时 `g_tp_wakeup_flag=1` + `enable_irq_wake()`；UNBLANK 时 `disable_irq_wake()`
  - 手势模式关闭：BLANK 时 `disable_irq()`（记录 suspended）；UNBLANK 时 `enable_irq()` 恢复
  - GPIO 操作增加 `gpio_is_valid()` 校验，避免非法 GPIO 调用
  - 手势触发：`input_report_key(KEY_WAKEUP, 1/0)` + `input_sync()`

## 配置方式

### DTS 配置（显示侧，overlay 中）

```dts
&mdss_dp0 {
	qcom,panel-notifier-support;            /* 使能 panel notifier 事件链 */
	qcom,edp-default-panel = <&edp_panel_node>;  /* eDP 默认面板 phandle */
};
```

### Kernel config

- 触摸驱动：vendor dlkm 模块（egalax / sis95xx）
- 显示：`CONFIG_DRM_MSM_DP=y`（yupik DP 子系统）

## 验证方式

### 验证命令

```bash
# 息屏后检查触摸 IRQ 唤醒能力
cat /proc/interrupts | grep -i "i2c\|touch"
# 查看驱动日志
dmesg | grep -i "sis\|egalax\|wakeup"
dmesg | grep -i "panel notifier"
```

### 预期结果

1. 息屏（BLANK）后驱动打印手势模式 IRQ 管理日志，`g_tp_wakeup_flag=1`
2. 触摸手势触发后系统从息屏状态唤醒（`KEY_WAKEUP` 上报）
3. `panel_event_notifier_register` 失败场景（ERR_PTR）不再误判成功
4. 无 en_gpio/rst_gpio 的板级配置不再报 GPIO 错误

### 实际结果

- 已 MERGED（#196796 / #196795）
- 与显示驱动配合完成手势唤醒链路验证
