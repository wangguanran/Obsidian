# GPIO 平台总览 — SM6115-A14

> **模块**: 13.GPIO | **厂商**: Qualcomm | **芯片**: SM6115 (scuba) | **平台**: SM6115-A14

## 平台信息

| 项 | 值 |
|----|----|
| SoC | Qualcomm SM6115 (scuba / Bengal 系) |
| 平台版本 | SM6115-A14（LA.VENDOR.13.2.1，项目分支 MT5205） |
| 设备形态 | Scuba IOT IDP（overlay：scuba-iot-idp-overlay.dts，`qcom,msm-id = <473 0x10000>, <474 0x10000>`） |
| 内核 | kernel_platform/msm-kernel（GKI + vendor 模块） |
| 相关驱动 | gpio-userspace（SE_RESET/MDB_RESET 导出）、meig_gpio_pulse（UIC 脉冲字符设备）、pinctrl-scuba（保留脚管理）、gpio-keys |

## 平台 GPIO 功能简表

| GPIO | 功能 | 说明 |
|------|------|------|
| GPIO14 | DB 检测按键 | gpio-keys KEY_F1（低有效，wakeup），#195886 解除 reserved |
| GPIO15 | 保留 | scuba_reserved_gpios 保留 |
| GPIO16/17 | MDB SE5 UART | 已释放给 UART（更早变更） |
| GPIO32 | Pulse 接口-1 检测 | meig_gpio_pulse IN（IRQ + hrtimer，默认 ACTIVE_HIGH） |
| GPIO33 | Pulse 接口-2 输出 | meig_gpio_pulse OUT（脉冲发射 25~500ms） |
| GPIO36 | MDB nRST | STM32F103 复位（gpio-userspace mdb_reset，空闲输出高，低有效） |
| GPIO102 | SE nRST | SE 复位（gpio-userspace se_reset，默认高，低有效） |
