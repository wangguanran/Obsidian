# yupik-SM7325-A13 USB 平台移植资料

> **版本号：v1.0** | **芯片**: SM7325 (yupik) | **平台**: SM7325-A13

## 平台版本

| 项目 | 内容 |
|------|------|
| SoC | Qualcomm SM7325 (yupik) |
| Android | A13 |
| 内核仓库 | LA.UM.9.14.1（分支 master_LA.4.0_MC9371） |
| 内核 | msm-5.4 |

## 硬件接口

| 信号 | 说明 |
|:---|:---|
| USB 串口 | WCH CH343（1a86:55da）多接口 CDC-ACM，devpath 1.3 |
| 第二串口设备 | 040b:a6b，devpath 1.2 |
| port | usb1 hub 下（devpath 依赖 hub 拓扑，变更需同步定制代码） |

|:---|:---|:---|

## 内核配置

```
CONFIG_USB_ACM=y|m        # cdc_acm 串口
CONFIG_USB_DEVICEFS=y     # usbfs（/dev/bus/usb）
# 若需用户态 detach：CONFIG_USB_DEVICE_CLASS 相关
```

## 验证命令

```bash
# 节点
ls -l /dev/ttyACM*
# 枚举
cat /sys/kernel/debug/usb/devices | grep -A3 1a86
# 固定 minor 复现/回归（usbfs 解绑→释放→节点恢复）
```
