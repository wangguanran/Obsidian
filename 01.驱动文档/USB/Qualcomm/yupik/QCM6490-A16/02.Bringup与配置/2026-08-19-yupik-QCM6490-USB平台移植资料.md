## 硬件接口

| 信号 | 说明 |
|:---|:---|
| USB0 | USB2/3 Type-C/Type-A（XHCI 控制器，PCIe 挂接） |
| PCIe | 非 USB 外设扩展（SSD/网卡），由 PcieConfigLib 使能 root port |
| 以太网 | AX88179 USB 网卡（UEFI 驱动 AX88179UsbEthDxe） |

## 编译命令

```bash
# UEFI 全量构建（Kodiak）
python -u mg_build_tools/mg_build.py -v WP -t kodiak,QcomToolsPkg -v LAA -r RELEASE,DEBUG
# 产物：xbl.elf 等（BOOT.MXF.1.0.c1/boot_images/boot/QcomPkg/SocPkg/Kodiak/Bin/LAA/RELEASE|DEBUG/）
```

## 配置要点

- 驱动清单：`Core.fdf` / `CoreAux.fdf.inc` / `Apriori.fdf.inc`（模块加入/移除需同步）；
- 平台参数：`uefiplat.cfg`（如 NumCpusFuseAddr）；
- USB 枚举调试：UsbEnumer/Xhci 的 `DEBUG ((EFI_D_ERROR, ...))` 打印（量产固件建议收敛）。
