## 硬件接口

- **USB**：USB 2.0/3.0 (dwc3@4e00000 + qusb_phy0 + eud)，Type-C / DIP ID 双模式切换（PMIC GPIO3 = USB_ID，GPIO19/GPIO103 VBUS 使能，GPIO108 HUB_RESET）
- **I2C**：QUPV3 SE1 (qupv3_se1_i2c) 等

## 驱动模块

- **USB**：dwc3 (dwc3-msm-core)、extcon-usb-gpio（DIP ID 检测）、qusb2 phy、eud
- **Charger**：pm2250_charger (smb5)
- 其它：pinctrl-scuba、gpio-keys 等
