# CellWise CW221X (SM6225-A13) 平台总览

> **版本号：v1.0**

## 平台信息

| 项目 | 内容 |
|------|------|
| 芯片 | CellWise CW221X 系列电量计（CW2215/CW2217 等） |
| SoC | Qualcomm SM6225（divar） |
| Android 版本 | Android 13 |
| 项目代号 | HXB_SLM927_YunZhuoKeJi / MeigLink 0028908 |

## 硬件接口

- **通信接口**：I2C（XBL 阶段直接通过 I2C 读取芯片 ID 寄存器识别型号）
- **电源**：电量计供电，I2C 挂载于 PMIC/SoC I2C 总线

## 驱动模块

- **XBL 电量计检测**：`MDPPlatformLib`（bootloader 侧电量计类型检测逻辑）
- **内核驱动**：CW221X 电量计驱动（Android 侧电量计 HAL 对接）
