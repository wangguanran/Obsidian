# 分析：SGM832 电源监控与钱箱驱动移植

**版本号：v1.0**
**对应文档：** SGM832电源监控与钱箱驱动移植.md

## 技术背景

Rigel A16（MC9392 机型）为收银/支付类设备，需要：
1. **SGM832**：SG Micro 电源监控芯片，I2C 接口，监测电源参数；原驱动基于 A14 msm-5.4 内核
2. **钱箱（cash drawer）**：收银机必备外设，GPIO 控制开合 + 检测状态
3. **外部 ADC**：通过 GPIO 采样外部模拟信号

A16 使用 5.15 GKI 内核（meigla/kernel/qcom），需将 A14 驱动移植并按 GKI kernel build (bzl) 体系接入。

## 代码改动分析

### sgm832.c（+362 行，新驱动）

- I2C 驱动框架：`i2c_client` + `delayed_work` 周期采样 + `kobject` sysfs 导出 + `power_supply`（usb_psy）
- `delaywork_func()` 读寄存器 0x01（`i2c_smbus_read_word_data`），`swapEndianness` 处理字节序（芯片大端输出，小端 SoC 需交换）
- 移植注意：A14→A16 内核 API 变化（如 `gpio_direction_output`、`of_*` API）已在代码中适配

### cash_drawer.c（+738 行，新驱动）

- char device（cdev + fs 接口）+ INPUT 事件双通道
- 平台设备框架 + GPIO 控制/检测
- Kconfig 依赖：`OF && GPIOLIB && INPUT`

### ext-adc-gpio.c（+350 行，新驱动）

- IIO/OF 依赖的 sysfs ADC 通道导出，compatible `ext,adc-driver`

### 构建接入

- `lahaina_consolidate.bzl` / `lahaina_perf.bzl`：consolidate/perf 两种内核变体都开 `CONFIG_SGM832/EXT_ADC_GPIO/CASH_DRAWER_DRIVER=m`
- `modules.bzl` 注册模块 → 编译为 kernel dlkm 加载

## 潜在风险

1. **I2C 采样频率**：`delayed_work` 周期未显式可见（代码中 schedule_delayed_work），过快增加 I2C 总线负载，过慢影响监控实时性
2. **GKI 限制**：5.15 GKI 内核中 vendor 模块需符合 GKI 符号约束（MODULE_LICENSE、symbol list）；若用到未导出符号需走 vendor hook
3. **钱箱 GPIO 冲突**：若 GPIO 与其它外设共享需查 DTS 冲突

## 回归测试建议

- SGM832 采样数据与万用表比对（电压/电流精度）
- 钱箱开合 × 100 次可靠性 + INPUT 事件上报
- 外部 ADC 通道读数准确性
- 系统 suspend/resume 后三个驱动恢复状态

## 与现有驱动架构的关系

- SGM832 与同厂商 SGM41513 充电芯片 belong 到同一 SG Micro 生态，但功能不同（monitor vs charger）
- Rigel 平台已在 yupik/QCM6490-A16 有 Camera/Audio/USB 等平台目录，本目录为 Charger 模块新增 SG Micro 芯片平台
- A14 源码同源（msm-5.4），本次为 A16 5.15 内核适配，未来可对比两版本差异
