# PN7221 RF参数合入

> **版本号：v1.0**

2025年11月4日 王冠然

更新配置文件**libnfc-nxp-rfExt.conf**

操作步骤：

1. 安装**NXP NFC Cockpit v8.3.0.0**，安装过程略。安装包：NxpNfcCockpit_08.03.00.zip

2. 天线厂提供XML配置文件，如：**5P7V_5611.xml**

3. 连接终端设备，执行脚本**C:\nxp\NxpNfcCockpit_v8.3.0.0\firmware\Secondary_Pn722x\Android\PN722x_UcBalAndroid_LogEnabled.bat**，注意查看执行过程是否有报错

   <img src="./PN7221 RF参数合入.assets/image-20251104113646275.png" alt="image-20251104113646275" style="zoom: 80%;" />

4. 执行指令**pnscr true**开启8059端口监听

   <img src="./PN7221 RF参数合入.assets/image-20251104113731980.png" alt="image-20251104113731980" style="zoom: 80%;" />

5. 打开工具**NXP NFC Cockpit v8.3.0.0**

   <img src="./PN7221 RF参数合入.assets/image-20251104114107544.png" alt="image-20251104114107544" style="zoom:80%;" />

6. 找到Extra

   <img src="./PN7221 RF参数合入.assets/image-20251104114252920.png" alt="image-20251104114252920" style="zoom:80%;" />

7. 导入XML配置文件

   <img src="./PN7221 RF参数合入.assets/image-20251104114344682.png" alt="image-20251104114344682" style="zoom:80%;" />

8. 保存**libnfc-nxp-rfExt.conf**配置文件

   <img src="./PN7221 RF参数合入.assets/image-20251104114413419.png" alt="image-20251104114413419" style="zoom:80%;" />

9. 配置文件内容如下

10. 执行脚本**C:\nxp\NxpNfcCockpit_v8.3.0.0\firmware\Secondary_Pn722x\Android\restore_NFC_HAL.bat**恢复hal库

    **注意：不执行该脚本的话nfc功能无法打开**

11. 将该文件push到设备中重启验证nfc功能

    ```bat
    adb root
    adb remount
    adb push libnfc-nxp-rfExt.conf /vendor/etc/libnfc-nxp-rfExt.conf
    adb reboot
    adb install --bypass-low-target-sdk-block "NFC Tools Pro v1.8 已付費繁體中文版.apk"
    ```
