# Qualcomm SM6225-A14 (khaje) 平台总览

> **版本号：v1.0**

## 平台信息

| 项目 | 内容 |
|------|------|
| 芯片 | Qualcomm SM6225 (khaje) |
| Android 版本 | Android 14 (API 34) |
| 内核版本 | 5.10 |
| 架构 | arm64 |
| VENDOR 树 | `LA.VENDOR.13.2.1` |
| 项目分支 | master_IOT_High_Mid_2024.SPF.1.0_MT5825 |
| PMIC | PM6125 (smb5 充电器) |

## 硬件接口

- **充电**：smb5 (pm6125_charger / pm7250b 系列)，支持 DCIN/POGO 充电、Dock 连接
- **POGO 引脚**：pogo_en_typea_5v_gpio（EN2）、pogo_en_hub_vcc_gpio（EN4）、pogo_sw_uart_usb_gpio 等

## 驱动模块

- **Charger**：`drivers/power/supply/qcom/smb5-lib.c`（smb5-lib 核心库，POGO 相关逻辑）
- **USB**：dwc3、fusb302/typec、eud
