# Qualcomm SM4490-A16 (MC5616/parrot) Sensor 平台总览

> **版本号：v1.0**

## 平台信息

| 项目 | 内容 |
|------|------|
| 芯片 | MC5616（基于 parrot/QCM4490） |
| Android 版本 | Android 16 |
| SSC 平台 | Netrani（ADSP SSC 传感器子系统） |
| 传感器 | BOM 仅使用 sc7a20 加速度传感器（sns_sc7a20） |

## 硬件接口

- **传感器接入**：由 ADSP SSC（Sensors SubSystem）统一管理，传感器 I2C 挂载于 SoC I2C 总线
- **SSC 配置**：`por.py`（POR 编译配置脚本）控制编译进 SSC 镜像的 vendor 传感器库

## 驱动模块

- **ADSP SSC**：`ADSP.HT.5.7/adsp_proc/ssc/chipset/netrani/por.py`（已归档）
- **传感器驱动库**：sns_sc7a20（保留）、其余 vendor 库（已裁剪）
