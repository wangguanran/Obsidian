# PN7221 (PN7220) 在 SM6225 平台移植资料

> **版本号：v1.0**

## 芯片信息

- **型号**：NXP PN7221 (PN7220 系列，驱动共用 `pn7220/` 目录)
- **厂商**：NXP Semiconductors
- **功能简述**：NFC 控制器，支持 ISO/IEC 14443 Type A/B、MIFARE、FeliCa 等

## 平台信息

- **芯片平台**：Qualcomm SM6225 (khaje)
- **Android 版本**：Android 14 (API 34)
- **内核版本**：5.10
- **架构**：arm64
- **VENDOR 树**：`LA.VENDOR.13.2.1`
- **QSSI 树**：`LA.QSSI.14.0`

## 硬件接口

| 信号 | GPIO/接口 | 说明 |
|:---|:---|:---|
| I2C SDA | — | I2C 数据线 |
| I2C SCL | — | I2C 时钟线 |
| IRQ | GPIO_70 | NFC 中断（下降沿触发） |
| VEN (legacy) | 扩展 IO (et6416_21.3) | 旧 BOM 使能脚，依赖扩展芯片 |
| VEN2 (primary) | GPIO_51 (AL5/CTLS_nPWDN) | 新 BOM 平台直驱使能脚 |
| MODE | 扩展 IO (et6416_21.2) | Forum/EMVCo 模式切换 |
| WAKEUP | GPIO_106 | NFC 唤醒 |
| 电源 | VDD_3V3 | 3.3V 供电 |

## 驱动源码索引

### 内核驱动

SM6225 平台使用 `pn7220_i2cms` 驱动变体（与 `pn7220` 共用同一套代码，仅编译配置不同）。

| 文件 | 说明 |
|:---|:---|
| `i2c_drv.c` | I2C 总线驱动层：probe、remove、IRQ handler、电源管理 |
| `i2c_drv.h` | I2C 驱动头文件 |
| `common.c` | 公共逻辑：NCI 协议处理、VEN 双路径控制 |
| `common.h` | 公共头文件：GPIO 结构体、DTS 宏 |
| `Kconfig` | 内核配置选项 |
| `Makefile` | 编译规则 |

驱动源码路径：`kernel_platform/msm-kernel/drivers/nfc/pn7220_i2cms/`

## 编译命令

### 单模块编译（NFC 驱动 ko）

```bash
cd LA.VENDOR.13.2.1/kernel_platform
export BUILD_CONFIG=./msm-kernel/build.config.msm.bengal VARIANT=consolidate
source build/_setup_env.sh
make -C msm-kernel O="$OUT_DIR" M=drivers/nfc/pn7220_i2cms modules -j64
```

### DTS/DTBO 编译

```bash
cd <CODES_TREE>
JOBS=64 TMPDIR=<tmpdir> ./make_dtbo.sh
```

### 全量编译

```bash
# 编译 vendor_boot + dtboimage
make vendorbootimage dtboimage
```
