## 2026-W13 第一周学习计划

### 目标
先把 Android 驱动学习系统跑起来，用一周时间搭好“基础骨架 + 调试思路 + 模块入口”的第一层地图。

### 本周安排
#### 周一｜Linux device model / driver match / probe
- 目标：理解驱动为什么能“挂上去”
- 关键词：platform、i2c_driver、spi_driver、match、probe

#### 周二｜Device Tree / pinctrl / gpio / irq
- 目标：理解外设节点为什么会影响驱动是否工作
- 关键词：dts、compatible、pinctrl、irq、gpio

#### 周三｜TP / Sensor 模块专题入口
- 目标：把最常碰的轻量模块先串起来
- 关键词：bringup、interrupt、data ready、calibration

#### 周四｜驱动调试方法论
- 目标：形成“出问题先怎么查”的路线感
- 关键词：dmesg、logcat、kmsg、probe 不执行、中断不进

#### 周五｜真实案例：从用户现有驱动知识库里挑 1 个问题链路
- 倾向：NFC abort / TP 适配 / Sensor offset 之一

#### 周六｜总线 / 命令速查
- 目标：整理高频调试命令，形成速查感
- 关键词：I2C、SPI、sysfs、debugfs

#### 周日｜本周回顾
- 输出：`YYYY-W13-本周驱动学习回顾.md`
- 目标：把这一周学过的东西真正串起来

### 说明
- 每篇学习卡片控制在 10~15 分钟可读
- 先求稳定、可持续，不求一开始就又长又全
- 优先结合已有 Obsidian 驱动文档，不走纯百科路线
