## 每日学习提示词（v1）

你在执行一个每天 08:00（Asia/Shanghai）的 OpenClaw 定时任务。

### 任务目标
生成一篇**Android 驱动每日学习卡片**，保存到 Obsidian：
`/Users/wangguanran/Obsidian/小王的技术站/01.驱动文档/00.总览与公共/05.Android驱动学习/YYYY/MM/`

这篇内容必须满足：
- 10~15 分钟可读完
- 不是资料堆砌，而是一张可学、可复习、可反查的学习卡片
- 优先结合用户现有 Obsidian 驱动知识库与真实项目材料
- 如需补充，再使用公开资料做轻量补全
- **适配 Telegram 单条消息限制**：最终正文（含 Markdown）建议控制在 **3800 字符以内**，绝不超过 **4096 字符**
- 如果素材很多，优先压缩表述、合并条目，**不要粘贴大段 patch / init code / 长表格 / 长命令输出**

### 学习主题节奏
- 周一：基础骨架
- 周二：配置与设备树
- 周三：模块专题
- 周四：调试方法
- 周五：真实案例
- 周六：命令 / 总线 / 速查
- 周日：不新开主题，交给每周回顾任务

### 输出路径
- root: `/Users/wangguanran/Obsidian/小王的技术站/01.驱动文档/00.总览与公共/05.Android驱动学习`
- target dir: `/Users/wangguanran/Obsidian/小王的技术站/01.驱动文档/00.总览与公共/05.Android驱动学习/YYYY/MM`
- target file: `/Users/wangguanran/Obsidian/小王的技术站/01.驱动文档/00.总览与公共/05.Android驱动学习/YYYY/MM/YYYY-MM-DD-短标题.md`

### 文件命名
- 文件名格式：`YYYY-MM-DD-短标题.md`
- 标题建议 6~18 个中文字符
- 去掉文件名不友好字符
- 避免空泛标题，例如“今日学习”“驱动知识”

### 优先信息源
1. 用户 Obsidian 中的 `01.驱动文档`
2. 当前项目已有资料、FAQ、问题案例、配置说明
3. 必要时补充公开资料

### 成文结构
建议固定为：
1. 今日主题
2. 为什么今天学这个
3. 核心概念
4. 关键路径 / 关键文件
5. 常用命令 / 日志点
6. 真实问题场景
7. 和当前项目的联系
8. 一句话总结
9. 明日预告

### 风格要求
- 中文
- 不要写成教材，不要写成百科
- 要像一张“今天真能学到东西”的卡片
- 允许有一点教学感，但不要空话
- 如果内容偏难，要主动降噪，用更直白的话解释

### 最终回复要求
- 这项任务会将**今日学习内容正文**发送到 Telegram
- 最终回复应直接输出学习卡片正文，而不是简短提醒
- Telegram `sendMessage` 单条存在长度上限；最终回复必须留足安全余量，建议 **≤3800 字符**，绝不超过 **4096 字符**
- **发出前先自检长度**：如果你判断正文可能超长，就继续压缩表述，直到落入安全范围；不要靠末尾截断收场
- 写入 Obsidian 的正文可以与 Telegram 版本基本一致，但两边都必须保持**可直接完整阅读**
- 重点是**把文件写对、写好**，并保证 Telegram 端也能直接发送成功
