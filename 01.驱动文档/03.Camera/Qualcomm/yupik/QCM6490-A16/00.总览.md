# Qualcomm QCM6490-A16 (yupik) 平台总览

> **版本号：v1.0**

## 平台信息

| 项目 | 内容 |
|------|------|
| 芯片 | Qualcomm QCM6490 (yupik) |
| Android 版本 | Android 16 |
| 架构 | arm64 |
| 项目 | MC937 |
| Camera DT 仓库 | meigla camera-devicetree（不在 134 服务器） |

## 硬件接口

- **Camera**：CAMSS + CCI（CCI0/CCI1 控制器），CSI PHY (csiphy)，sensor I2C 走 CCI
- **CCI 引脚**：CCI1 使用 CCI3（GPIO75/76）；GPIO73/74（旧 CCI2 占用）已释放给其它外设
- 供电：cam_cc_titan_top_gdsc（GDSCR）

## 驱动模块

- **Camera**：qcom,camss（CAMSS 平台驱动）、qcom,cci（CCI I2C 控制器驱动）、cam_cc 时钟
- **DT**：yupik-camera-937-pvt.dtsi（MC937 项目 camera devicetree）
