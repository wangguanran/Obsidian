# Qualcomm SM6225-A16 (SLM927P/khaje) 平台总览

> **版本号：v1.0**

## 平台信息

| 项目 | 内容 |
|------|------|
| 芯片 | SLM927P（基于 khaje/SM6225） |
| Android 版本 | Android 16 |
| 项目基线 | LA.VENDOR.13.2.1 |
| 模块 | GPIO（TLMM 引脚复用与全引脚测试） |

## 硬件接口

- **GPIO**：TLMM（Top Level Mode Multiplexer），引脚复用（pinmux）通过 DTS pinctrl 配置
- **特殊功能引脚**：部分 GPIO 复用为 I2C/UART/SPI 等专用功能

## 驱动模块

- **GPIO 框架**：pinctrl/msm TLMM 驱动
- **测试脚本**：`device/qcom/bengal_515/SLM927P_gpio.sh`
- **DT**：`kernel_platform/qcom/proprietary/devicetree/qcom/khaje.dtsi`
