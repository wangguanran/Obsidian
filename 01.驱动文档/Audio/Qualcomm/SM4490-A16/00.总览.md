# Qualcomm SM4490-A16 ([项目代号]/parrot) 平台总览

> **版本号：v1.0**

## 平台信息

| 项目 | 内容 |
|------|------|
| 芯片 | [项目代号]（基于 parrot/QCM4490） |
| Android 版本 | Android 16 |
| 项目基线 | LA.VENDOR.1.0.R1 |
| 音频通路 | LPASS（lpass-cdc 编解码器），无 WCD RX / Awinic I2C PA |

## 硬件接口

- **音频通路**：LPASS 内建 codec（lpass-cdc），VA 通路保留，RX 通路（RX macro + SWR master）未使用
- **外置音频**：无 WCD 系列 RX codec、无 Awinic I2C PA
- **RX 通路状态**：DTS 中禁用 rx-macro 及 swr-mstr；RX CDC DMA DAI link 通过 `#if 0` 编译屏蔽

## 驱动模块

- **音频驱动**：`lpass-cdc-rx-macro.c`（RX macro，已禁用）、`waipio.c`（lpass-cdc DAI link 定义）
- **DT**：`parrot-audio-overlay.dtsi`（禁用 rx-macro/swr-mstr）、`parrot-audio-qrd.dtsi`（删除无效 RX_TX DEC 路由）
