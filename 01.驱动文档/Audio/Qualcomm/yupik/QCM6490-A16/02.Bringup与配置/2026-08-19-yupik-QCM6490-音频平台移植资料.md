## 硬件接口

| 信号 | 引脚/资源 | 说明 |
|:---|:---|:---|
| 扬声器 | WSA883x ×2（SoundWire） | WSA_SPK1/2 OUT |
| DMIC0/1 | GPIO150/151（右侧） | 数字麦克风，BIAS1 |
| DMIC2/3 | GPIO152/153（左侧） | 数字麦克风，BIAS1 |
| MIC_BIAS1/2 | TLMM 96 / 97 | vcc-micbias1/2-gpio 使能 |
| 音频开关 | fsa4480 I2C | 禁用（=0），走板载模拟通路 |

## DTS 配置要点

各 SKU overlay 需声明：`qcom,model`、`asoc-codec`（stub+bolero+wsa883x×2）、`vcc-micbias1/2-gpio`、`fsa4480-i2c-handle=<0>`、完整 `qcom,audio-routing`（WSA 双声道 + TX/VA DMIC0~3 + VCC MIC BIAS1）。MC934 无 WSA：`wsa_macro`/`wsa883x_0221/0222` disabled、`qcom,num-macros=<3>`、VA/RX macro `/delete-property/ qcom,*-swr-gpios`。

## 编译命令

```bash
cd audio-devicetree
make dtbo        # 生成 dtbo，产物清单由 Kbuild 的 dtbo-y 控制
# 整包：随版本构建（vendor_boot 打包 dtbo.img）
```

## 配置检查

- `dtboimg.cfg` 与 Kbuild 一致，无缺失/多余 dtbo；
- `/proc/asound/cards` 声卡名 = `lahaina-yupikidp-mcXXX-snd-card`；
- `tinymix` 可看到 WSA 与 DMIC 通路。
