# Audio 平台总览 — QCM6490-A16 (yupik)

## 平台信息

| 项 | 值 |
|----|----|
| SoC | Qualcomm QCM6490 (yupik / lahaina 家族) |
| 平台版本 | QCM6490-A16 |
| audio-devicetree 仓库 | meigla/platform/vendor/qcom/opensource/audio-devicetree（分支 Develop_QCM6490.LA.6.0_VENDOR_QCOM_Platform_Elo_[项目代号]） |
| 音频框架 | ASoC：yupik_snd machine + bolero codec + WSA883x 功放 |
| SKU 变体 | MC933 / MC934（无 WSA）/ MC936 / MC937 / [项目代号] / MC9392 |

## 硬件接口

| 通路 | 说明 |
|------|------|
| WSA 扬声器 | wsa883x_0221/0222（SoundWire），WSA_SPK1/2 OUT |
| DMIC0~3 | GPIO150~153，BIAS 由 TLMM 96/97（vcc-micbias1/2）控制 |
| MIC BIAS | VCC MIC BIAS1（DMIC 通路共用） |
| Type-C 音频 | fsa4480-i2c-handle = <0>（使用板载模拟通路） |
