# LCD 平台总览 — SM6115-A14

> **模块**: 01.LCD | **厂商**: Qualcomm | **芯片**: SM6115 (scuba) | **平台**: SM6115-A14

## 平台信息

| 项 | 值 |
|----|----|
| SoC | Qualcomm SM6115 (scuba / Bengal 系) |
| 平台版本 | SM6115-A14 |
| AP 源码 | LA.VENDOR.13.2.1（分支 MT5205），vendor/qcom/proprietary/display-devicetree/ |
| BP 源码 | iot-high-mid-2024-spf-1-0_amss_standard_oem（分支 master_meig），BOOT.XF.4.1/ |
| 显示框架 | SDE (Snapdragon Display Engine)，DSI video 模式 |
| 背光 | PM2250 PWM3（pm2250_pwm3），bl_ctrl_pwm 模式，PWM 周期 50us（20kHz） |
| 面板 | JD9365DA 720p video（主屏）、ST7701S BOE397 480p video、TD4330（参考） |

## LCM 电源与 GPIO（MT5205）

| 信号 | GPIO/资源 | 说明 |
|------|-----------|------|
| LCD_IOVCC_EN | GPIO111 | IOVDD 1.8V（vddio） |
| LCM_VDD2V8_EN | GPIO112 | VCC 2.8V（avdd） |
| DISP_BIAS_EN | GPIO105 | avee |
| LCD_RST_N | GPIO82 | 面板复位 |
| LCM_TE | GPIO81 | TE（mdp_vsync） |
| BL_FB | GPIO24 | 背光亮度选择（4inch LOW/40mA，5inch HIGH/80mA，由 BP 设置） |
| BL_PWM | PM4125 GPIO2 / PM2250 PWM3 | 背光 PWM |
